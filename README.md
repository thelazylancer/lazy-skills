# lazy-skills

A personal collection of reusable ChatGPT Skills.

## Skills

### image-prompt-engineer

Turns natural-language image requests and reference images into clear, conflict-free, generation-ready prompts.

Key capabilities:
- Text-to-image prompt engineering
- Single-reference image editing instructions
- Multi-reference role mapping
- Preserve / Change / Ignore constraints
- People photography and casual phone-photo composition
- Text-heavy thumbnails and diagrams
- Prompt conflict and spatial-coherence checks

See [image-prompt-engineer/SKILL.md](image-prompt-engineer/SKILL.md) for the skill entrypoint.
