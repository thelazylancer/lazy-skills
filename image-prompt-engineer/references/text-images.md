# Text-heavy images, thumbnails, and diagrams

## Exact text

Separate literal image text from descriptive instructions. Explicitly say that only the quoted strings should appear.

Specify hierarchy rather than merely saying "make it prominent":
- exact line breaks;
- largest/secondary/supporting text;
- alignment and margins;
- reserved negative space;
- contrast against background.

For critical prices, dates, product names, legal wording, or exact typography, warn that direct image generation may still introduce text errors and recommend generating the visual background first and adding exact text in an editing/layout tool when accuracy is mandatory.

## Diagrams

Start from one intended takeaway. Select a structure that matches the relationship:
- sequence -> flow/process;
- comparison -> columns/table-like layout;
- hierarchy -> tree/pyramid;
- components -> labeled system diagram;
- three key checks -> three-card or three-step layout.

Prioritize factual/relational clarity before decoration. Keep labels short enough to remain legible at the intended display size.
